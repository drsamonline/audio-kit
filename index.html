audio-kit

Synthesis, theory, patterns and notation. Zero dependencies, one file, no audio assets.

The rule. Game music is patterns, not files. A pattern is a few KB of data and plays through WebAudio; an audio file is megabytes.

What's in it

  • music — notes, intervals, scales, chords, transposition
  • synth — ADSR, oscillator voices, filters, noise, a mixer
  • seq — a pattern sequencer (rows × channels → timed events)
  • notation — a staff layout
  • sonify — bytes to sound
  • master — loudness match + limiter (a matching aid, not an engineer)

Usage and the notes are in the README. Tests: node test-node.js.
